## Пет-проект — WebGL2 City

**Процедурный 3D-город на чистом WebGL2 (без движка): ядро без фреймворка + приложение на Angular**

Город генерируется по seed и рендерится в реальном времени. Есть orbit-камера и три инструмента: выбор здания, измерение расстояний и навигатор кратчайшего пути A→B.

- **Рендеринг:** весь город (тысячи зданий) рисуется одним `drawElementsInstanced` (то, что в Three.js даёт `InstancedMesh`). Динамические тени (shadow mapping): depth-пасс, PCF-сглаживание, slope-scaled bias, карта теней привязана к камере. Освещение Half-Lambert.
- **Взаимодействие:** orbit-камера на сферических координатах (аналог `OrbitControls`), пикинг зданий лучом ray–AABB (аналог `Raycaster`) с панелью свойств. Измерение расстояний со снепингом к углам зданий и перекрёсткам в экранных пикселях. HTML-метки поверх canvas через проекцию world→screen.
- **Навигатор A→B:** явный граф дорог и поиск кратчайшего пути A\* с допустимой эвристикой на бинарной min-куче.
- **Архитектура:** монорепозиторий на npm workspaces. Вся логика сцены — в ядре на TypeScript без зависимостей от фреймворка (рендер, камера, лучи, алгоритмы, данные для UI); Angular-приложение — тонкие адаптеры `inject*`. Ресурсы ядра возвращают свою очистку и подключаются к `DestroyRef`, рендер принимает кадр как данные. На том же ядре та же сцена реализована и на React + MobX.
- **Angular:** zoneless + signals, standalone, `OnPush`. Кадр собирается `computed` из сигналов и рисуется в `afterRenderEffect` только при изменении состояния, в покое нагрузки нет. Данные города и камера раздаются фичам через DI (`InjectionToken`, scoped-сервис), без ручного проброса зависимостей.
- **Состояние (@ngrx/signals):** scoped store — слайсы по фичам зарегистрированы в `providers` компонента сцены и живут вместе с ней. Поток однонаправленный: клик → луч / A\* → метод стора → сигналы → UI и рендер. Тяжёлые вычисления остаются вне стора, в сторах — мировые координаты, в экранные их переводит отдельный сервис.
- **Производительность:** метки поверх сцены — host-элементы с пустым шаблоном; позиция пишется в DOM из `afterRenderEffect` через CSS-переменные (`@property`) и `transform`, так что при вращении камеры шаблоны не проверяются. Сигналы с `equal` по значению отсекают лишние пересчёты. Проверено профилировщиком Chrome: стабильные 60 FPS в prod-сборке.
