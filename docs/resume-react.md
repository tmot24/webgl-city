## Пет-проект — WebGL2 City

**Процедурный 3D-город на чистом WebGL2 (без движка): ядро без фреймворка + приложение на React и MobX**

Город генерируется по seed и рендерится в реальном времени. Есть orbit-камера и три инструмента: выбор здания, измерение расстояний и навигатор кратчайшего пути A→B.

- **3D:** весь город рисуется одним `drawElementsInstanced` (то, что в Three.js даёт `InstancedMesh`), динамические тени (shadow mapping), orbit-камера (аналог `OrbitControls`), пикинг лучом ray–AABB (аналог `Raycaster`), поиск пути A\* по графу дорог.
- **Архитектура:** монорепозиторий на npm workspaces. Вся логика сцены — в ядре на TypeScript без зависимостей от фреймворка; React-приложение — хуки над ядром, функция очистки ресурса ядра сразу становится cleanup эффекта. На том же ядре та же сцена реализована и на Angular.
- **MobX:** сторы классами на `makeAutoObservable`, собранные по паттерну RootStore; скоуп на компонент сцены через `useState` + Context. `observableRef` и `observableShallow` для неизменяемых данных вместо глубоких Proxy.
- **Рендер вне React:** камера и кадр — в MobX, отрисовка через `reaction` с rAF-планировщиком. Вращение камеры перерисовывает canvas, но не вызывает ни одного ре-рендера компонента.
- **Производительность UI:** метки поверх сцены рендерятся один раз, позицию и текст пишет `reaction` прямо в DOM через CSS-переменные и `transform`, одинаковые данные отсекаются сравнением по содержимому. `observer` только на компонентах, читающих стор; панели режимов вынесены, чтобы смена режима не перерисовывала сцену.
- **React 19:** `useEffectEvent` для колбэков подписок, `useLayoutEffect` для первого кадра без вспышки, StrictMode как проверка освобождения GL-ресурсов и слушателей, ESLint `react-hooks`.
